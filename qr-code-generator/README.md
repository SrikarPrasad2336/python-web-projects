# QR Studio – QR Code Generator

A modern, responsive QR Code Generator built with Python Flask, HTML, CSS, and JavaScript. Generate customized QR codes from text, URLs, and other information, then download them as PNG images.

## Features

- **Instant QR Generation:** Convert text and URLs into QR codes.
- **Custom Colors:** Choose foreground and background colors.
- **Color Presets:** Quickly apply Classic, Purple, Emerald, and Rose themes.
- **Live Character Counter:** Track input length up to 2,000 characters.
- **PNG Download:** Download generated QR codes for sharing or printing.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Input Validation:** Handles empty content, invalid colors, and oversized input.
- **Privacy-Friendly Generation:** QR images are generated by the Flask backend without relying on a third-party QR generation service.

## Installation and Setup

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

Open the repository and navigate to the project folder:

```bash
cd python-web-projects/qr-code-generator
```

Replace the repository URL placeholder with your actual GitHub repository URL.

### 2. Create a virtual environment

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS/Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open the application in your browser:

**http://127.0.0.1:5000**

## How to Use

1. Enter text, a URL, or other information in the input field.
2. Select a foreground and background color, or choose a preset.
3. Click **Generate QR Code**.
4. Preview the generated QR code.
5. Click **Download QR Code** to save the PNG image.
6. Scan the downloaded image with a compatible QR scanner to verify its contents.

## API Endpoint

### Generate QR Code

`POST /api/generate`

Request body:

```json
{
  "content": "https://example.com",
  "foreground": "#111827",
  "background": "#FFFFFF"
}
```

A successful request returns a PNG image. Invalid input returns a JSON error response with an appropriate HTTP status code.

## Validation and Limitations

- Empty content is rejected.
- Content is limited to 2,000 characters.
- Foreground and background colors must be valid and different.
- QR codes contain the information supplied by the user. They do not automatically verify the safety or destination of a URL.
- Supported content and scanning behavior depend on the QR reader.
- The Flask development server is intended for local development. Production deployment requires a suitable production WSGI server and hosting configuration.
